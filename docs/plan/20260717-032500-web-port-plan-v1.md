# Ymir Web 化移植计划 v1

- 时间：2026-07-17 03:25 UTC
- 依据：`docs/research/20260717-031000-env-check.md`、`docs/research/20260717-031800-core-api-and-portability-research.md`

## 目标

让用户在浏览器中运行 Ymir Sega Saturn 模拟器：上传 BIOS 与光盘镜像 → 全速运行游戏（画面 + 声音 + 键盘/手柄输入 + 存档持久化）。**不修改上游核心逻辑**，新增代码集中在一个独立的 web 前端工程中。

## 总体架构（前后端分离）

```
浏览器
├── index.html / main.js        ← 自写 JS 前端（画面、音频、输入、存档、UI）
├── ymir-web-audio-worklet.js   ← WebAudio 音频供给
└── ymir-web.wasm + ymir-web.js ← Emscripten 产物
      └── ymir-web-bridge.cpp   ← 自写 Embind 桥接层（唯一新 C++）
            └── ymir-core (static lib)  ← 上游核心，原样编译（仅 1 处 CMake 补丁）
```

关键决策：**不移植 `apps/ymir-sdl3`**（179 个 cpp 的 ImGui 桌面 UI，移植价值低、依赖重）。官方设计本来就支持核心库独立使用（`Ymir_LIBRARY_ONLY`），JS 前端 + 薄桥接层是最小侵入方案。

## 里程碑

| # | 里程碑 | 验收标准 |
|---|---|---|

## 工作分解（WBS）

### M1 构建环境
- `git submodule update --init --recursive --depth 1`（ymir 仓库内）
- emsdk：克隆到 `tools/emsdk/` → `./emsdk install latest` → `activate`。全部文件在工作目录内，符合"不污染全局环境"。（uv/conda 不适用：Emscripten 非 Python 包；podman 方案作为备选）

### M2 核心 wasm 化
- **补丁 1（唯一上游补丁）**：`ymir/cmake/DetectArchitecture.cmake` 增加 Emscripten 分支（`if(CMAKE_SYSTEM_NAME STREQUAL "Emscripten")` → 走 generic，不 FATAL_ERROR）
- 自建包装工程 `web/CMakeLists.txt`：`add_subdirectory(../ymir)`（自动 `Ymir_LIBRARY_ONLY=ON`，绕开 vcpkg 与 apps）+ 桥接 executable
- 编译选项：`-fexceptions`（CHD loader 需要）、`-O3`、单线程（不加 `-pthread`，免 SharedArrayBuffer/COOP/COEP）、`-sALLOW_MEMORY_GROWTH`、`-sINITIAL_MEMORY` 视镜像大小定（CHD 解压进内存，先给 512MB，可增长）
- 预期风险：预编译头（PCH）可能拖慢/出问题 → 备用方案关 PCH；IPO/LTO 若报错 → `-DYmir_ENABLE_IPO=OFF`

### M3 桥接层（`web/bridge/ymir_web_bridge.cpp`）
Embind 暴露（JS 侧 `Module.*` 可调）：

| 函数 | 说明 |
|---|---|
| `init()` | 构造 Saturn；关闭 threadedVDP1/2（单线程）；注册视频/音频/输入静态回调 |
| `loadIplRom(bytes)` | `Saturn::LoadIPL(span)`，JS 传 Uint8Array |
| `loadDiscFromMEMFS(path)` | JS 已把镜像文件写入 MEMFS（Emscripten FS API），桥接层调 `media::LoadDisc(path, disc, preloadToRAM=true)` + `Saturn::LoadDisc` |
| `runFrame()` | 调 `RunFrame()`；视频回调把帧拷到内部缓冲 |
| `getFramebuffer()` / `getFrameWidth/Height()` | 返回 `typed_memory_view`，JS 包成 `ImageData` 上 Canvas |
| `readAudioSamples(maxN)` | 从 S16 立体声环形缓冲取出攒下的采样（Float32 交错） |
| `setPadState(player, mask)` | 写按键位图；外设报告回调（拉模型）把它喂给核心 |
| `saveState()` → bytes / `loadState(bytes)` | cereal 序列化到内存流 |
| `getBackupRam()` → bytes / `setBackupRam(bytes)` | `ReadAll()` / 逐字节 `WriteByte` |
| `reset(hard)` / `setRegion(...)` | 辅助控制 |

### M4 Web 前端（`web/shell/`）
- `index.html`：Canvas + 文件选择（BIOS、光盘镜像）+ 简单状态栏；零框架、零构建步骤（原生 ES Module）
- `main.js`：加载 wasm → 读文件到 MEMFS → `init/runFrame` 主循环（rAF 驱动，音频缓冲水位辅助节流）
- `audio-worklet.js`：AudioWorkletProcessor 每 128 采样从共享缓冲拉 PCM
- 输入：键盘映射（方向键 + ZXCV/AS/Enter/Shift → Saturn 手柄），后续加 Gamepad API
- 画面：Canvas 2D `putImageData`（像素格式 R,G,B,X 与 RGBA 完全对齐，零转换）

### M5 持久化
- IndexedDB（原生 API，不引依赖）：键 = 游戏哈希；值 = 备份 RAM（定期/退出时保存）、savestate 槽位

### M6 文档与审计
- `docs/architecture/` 架构图与数据流；`docs/impl/` 每轮迭代记录；glossary 持续补充
- 提交前审计：检查代码/文档中无主机路径外泄、无密钥、无个人信息；**不分发 BIOS/游戏 ROM**（版权）

## 明确不做（Out of Scope，首版）
- 多线程渲染（SharedArrayBuffer + COOP/COEP）—— 性能不足时再迭代
- ImGui 调试 UI、金手指、倒带（rewind）、网络更新检查、MIDI、主机物理光驱
- SIMD（-msimd128）优化 —— 先保证正确性

## 回退/备选方案
- emsdk 本地下载失败 → podman 跑 `emscripten/emsdk` 镜像构建
- CHD 依赖编译失败 → patch 掉 `loader_chd`（只留 cue/bin、iso）
- 单线程性能不足 → 方案 B：`-pthread` + Worker 内跑模拟 + COOP/COEP 头
